====================================================
Unlock Flow — Cross-Browser & Extension Guide
====================================================

၁။ Desktop PC (Chrome, Edge, Brave, Opera)
----------------------------------------------------
1. Chrome browser တွင် `chrome://extensions` သို့ သွားပါ (Edge တွင် `edge://extensions`)
2. ညာဘက်အပေါ်ထောင့်ရှိ "Developer mode" ကို ON ပါ
3. "Load unpacked" ကို နှိပ်ပြီး ဤ `Unlock-Flow` folder (သို့မဟုတ် Unlock-Flow.zip ဖြေထားသော folder) ကို ရွေးပေးပါ
4. ပြီးပါက https://flow.google.com သို့ တိုက်ရိုက် ဝင်ရောက် အသုံးပြုနိုင်ပါပြီ။

၂။ Android ဖုန်းများတွင် အသုံးပြုနည်း
----------------------------------------------------
* မှတ်ချက်: Official Google Chrome Android တွင် Google က Extension စနစ်ကို ပိတ်ထားပါသည်။
* ထို့ကြောင့် Chrome Extension စနစ်ပါဝင်သော အောက်ပါ Browser တစ်ခုခုကို အသုံးပြုရပါမည်-
  1. Google Play Store မှ "Kiwi Browser" (သို့မဟုတ် "Firefox for Android") ကို Install လုပ်ပါ
  2. Kiwi Browser တွင် Chrome Extension ရော Tampermonkey ပါ ၁၀၀% အပြည့်အဝ အသုံးပြုနိုင်ပါသည်
  3. Kiwi Browser ဖြင့် `index.html` ကို ဖွင့်၍ "Install unlock-flow.user.js" ကို နှိပ်ပြီး အသုံးပြုနိုင်ပါသည်။

၃။ iPhone / iPad (iOS) တွင် အသုံးပြုနည်း
----------------------------------------------------
1. App Store မှ "Orion Browser" (Chrome extension support ပါဝင်သည်) ကို ဒေါင်းလုဒ်ဆွဲပါ
   (သို့မဟုတ် Safari တွင် "Userscripts" app / "Stay" app ကို install လုပ်ပါ)
2. `unlock-flow.user.js` ကို သွင်းယူပြီး flow.google.com သို့ ဝင်ရောက်နိုင်ပါပြီ။
